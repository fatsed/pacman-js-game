# Pacman JS Game

A simple browser-based Pacman game built with **HTML**, **CSS**, and **JavaScript**.

This is one of my older web development practice projects. I uploaded it to GitHub as part of organizing my previous projects and improving them step by step.
## Demo

The game runs directly in the browser by opening the `index.html` file.

## Features

- Pacman movement using keyboard arrow keys
- Game start with the `N` key
- Ghost movement
- Score system
- Collision detection
- Game over screen
- Built with JavaScript and HTML Canvas
## How to Play

1. Open `index.html` in your browser.
2. Press `N` to start the game.
3. Use the arrow keys to move Pacman.
4. Avoid the ghosts and collect the dots.
## Technologies Used

- HTML
- CSS
- JavaScript
- Canvas API
